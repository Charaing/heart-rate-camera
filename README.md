# ♥ 심박 — 카메라 심박수 측정

휴대폰 후면 카메라와 플래시에 손가락을 대면 심박수(BPM)를 측정하는 웹앱입니다.

**▶ 바로 사용하기: https://charaing.github.io/heart-rate-camera/**

## 원리 (PPG, 광혈류측정)
플래시 빛이 손가락을 통과할 때 심장이 뛸 때마다 혈액량이 변해 카메라에 들어오는 빨간빛의 밝기가 미세하게 바뀝니다.
프레임마다 빨간 채널 평균을 구한 뒤 추세 제거 → 평활화 → 피크 검출(+자기상관 교차검증)로 박동 간격을 계산합니다.

## 사용법
1. 휴대폰에서 링크를 열고 **측정 시작** → 카메라 권한 허용
2. 검지로 후면 카메라와 플래시를 함께 살짝 덮기
3. 움직이지 않기 — 박동마다 하트·원·파형이 실시간으로 뛰고, 박동 수·박동 간격·순간 BPM이 표시됩니다
4. 25초가 지나면 결과가 기록에 저장되고, 「계속 측정」을 켜두면 중지할 때까지 실시간으로 계속 보여줍니다 (🔊 박동음 옵션)

- 플래시 자동 켜기는 안드로이드 Chrome에서 지원됩니다. iPhone Safari는 플래시 제어가 안 될 수 있어 밝은 곳에서 측정하세요.
- 모든 처리는 기기 내에서만 이루어지며 영상은 저장/전송되지 않습니다.
- 의료기기가 아니며 결과는 참고용입니다.
